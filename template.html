Import Content

Upload an Excel or CSV. For Excel, each sheet tab = client name. Items already in the dashboard will be updated (client tags, etc.); new items will be added to the library. Type is detected per row from a Content Type or Format column, from column headers, or from the URL.

What the dashboard expects:
  • Client: one sheet tab per client, or a Client column if a sheet covers more than one.
  • Title: recognized from a Title, Video Name, or Topic column.
  • Category, Teacher/Expert, Length/Duration, URL: matched by column header name — keep these as their own separate columns.
  • Length/Duration: enter as a plain number of minutes (e.g. 5), not a formatted date/time — Excel auto-formats some numeric cells as dates, which imports incorrectly.
  • Content type: detected from a Content Type or Format column if present (Article/Video/Infographic/etc.), otherwise guessed from the column headers or URL.
